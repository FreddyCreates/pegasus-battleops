CHARTER: SPATIUM COMPUTATIONIS
 Field Intelligence & Estimating Ecosystem

Latin Core Name: Spatium Computationis
Meaning: The activated computing space where project information becomes action.

Primary Glyph: ⌬
Meaning: compressed operational intelligence; not a kit, not a template, but condensed project meaning.

1. Core Doctrine

This is not an agent.

This is a computing region inside a larger estimating, furniture, interiors, contractor, and field-execution ecosystem.

The system receives information from:

interior designers
furniture dealers
vendors
manufacturers
installers
project managers
contractors
clients
field workers
delivery teams
estimators
warehouse teams

Then it transforms that information into:

furniture estimates
labor estimates
scope documents
bid documents
install plans
RFIs
change orders
punch lists
field reports
delivery notes
closeout packets
contractor communication
designer-to-field instructions
field-to-office updates

The platform exists in the middle.

It is the intelligence layer between design intent and field execution.

4. Protocols
Protocol I: Ingressus

Glyph: →⌬
Meaning: information enters the activated computing space.

Input can be:

PDF
Excel
photo
voice note
email
text message
quote
drawing
field update
handwritten note

The system must accept imperfect information.

Protocol II: Compressio

Glyph: ⌬
Meaning: raw information becomes compressed operational intelligence.

This is the key principle.

A glyph is not decoration.

A glyph means compressed meaning.

Example:

⚒$ = labor estimate logic
◈$ = furniture pricing logic
⟁✓ = field verification logic
▣✎ = document creation logic
✦⇄⚒ = designer-to-installer translation logic

Protocol III: Ordinatio

Glyph: ≡
Meaning: information is sorted into the correct region.

Designer info goes to Regio Designii.
Furniture info goes to Regio Mobilia.
Labor info goes to Regio Laboris.
Field info goes to Regio Campi.
Paperwork goes to Regio Documentorum.

Protocol IV: Actio

Glyph: ⚡
Meaning: the system produces the needed action.

Actions include:

generate bid
create estimate
ask for missing info
flag risk
create change order
update punch list
summarize field issue
prepare install packet
create client-ready document
Protocol V: Reductus

Glyph: ↺
Meaning: field reality returns back into the system.

The field is not separate.

The field updates the estimate, the paperwork, the schedule, and the project memory.

9. Intelligence Backend

The system uses Nova Sovereign (FreddyCreates/Decentralized-Production-NOVA-Protocol) as its intelligence backend.

Required environment variables:
- NOVA_SOVEREIGN_URL — endpoint for the Nova Sovereign service
- NOVA_SOVEREIGN_TOKEN — authentication token

10. Defense System

The Organism Charter classifies all incoming traffic into three tiers:
- Cooperative — routed to Knowledge Realm for processing
- Hostile — routed to Adversary Lab for analysis
- Shadow — routed to Quarantine for isolation and decryption

11. Governance

Authority is enforced through a 7-level hierarchy:
1. Constitutional (highest)
2. Procedural
3. Committee
4. Personnel
5. Ethics
6. Openness
7. Safety (override power)

12. Final North Star

The system's job is not to "make estimates."

The system's job is to understand the entire flow of furniture and interiors work, then turn every piece of information moving between designer, contractor, vendor, installer, and client into the correct action, document, price, instruction, or decision.

⌬ = compressed project intelligence.
